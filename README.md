# SHK Theorie Trainer V4

## Drei Hauptbereiche
1. 📝 Prüfungsmodus
2. 📚 Fragebögen zum Lernen
3. 🛠️ Diagnose – vollständiger interaktiver SHK Diagnose Simulator

## Theorie
- 1100 Theoriefragen
- Prüfungsmodus: 30 Fragen, 30 Sekunden je Frage
- Lernmodus ohne Zeitlimit
- Kategorien inklusive „Symbolabfrage“
- 80 technische Symbol-/Bauteilerkennungsfragen

## Diagnose
Der Diagnosebereich basiert auf dem SHK Diagnose Simulator Pro und enthält die interaktive Heizungsanlage, Bauteilprüfung, Messungen und Störungssuche.

Mobile/iPhone optimiert.
